# Aquariz v2

A self-contained redesign of the Aquariz parent site and Flanora product site.

- `index.html` is the Aquariz parent/manufacturing page.
- `flanora.html` is the Flanora product and ordering page.
- `styles.css` and `app.js` are shared by both pages.
- `assets/images/` contains v2-local copies of the current image assets.

This folder is isolated from the current production files. It is plain static HTML/CSS/JS and can be opened directly or served from any static host.
