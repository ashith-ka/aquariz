# Flanora – Premium Kerala-Based Ginger & Garlic Pastes

## 🌿 Project Overview

**Flanora** is a premium FMCG food brand based in Kerala, India, specializing in 100% pure cold-pressed crushed ginger and garlic pastes. This website reflects the brand's commitment to "Pure, Simple, and Powerful" ingredients through a clean, high-converting digital experience.

## ✨ Key Features

- **Mobile-First Design:** Optimized for fast loading on Indian mobile networks and budget-to-flagship devices.
- **WhatsApp Integration:** One-tap dynamic WhatsApp ordering with auto-prefilled product and pack size selection.
- **Interactive Product Selector:** Pack size buttons that calculate kitchen yield and generate instant WhatsApp order links.
- **Responsive Navigation:** Sticky navbar with mobile drawer menu and bottom action bar.
- **SEO Ready:** Semantic HTML structure, meta tags, Open Graph tags, JSON-LD structured data.
- **Accessibility:** ARIA labels, keyboard-navigable, focus-visible states.

## 🛠️ Tech Stack

- **Languages**: HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- **Icons**: [Font Awesome 6.5.1](https://fontawesome.com/)
- **Fonts**: [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) (body) & [Playfair Display](https://fonts.google.com/specimen/Playfair+Display) (display) via Google Fonts
- **No frameworks, no build tools, no package managers**

## 📁 File Structure

- `index.html`: The Flanora sub-brand flagship website.
- `404.html`: Custom error page for `/flanora/` routes.

## 🚀 Deployment

This is a static single-file site requiring zero build pipeline or server-side dependencies. Deploy to any static host (GitHub Pages, Netlify, Vercel, etc.).
